## Code Style Guidelines
- TypeScript project with strict typing preferred
- Use Zod for schema validation
- Follow OpenCode plugin patterns for command definitions
- Markdown files for documentation and configuration
- Import statements should use ES6 syntax
- Error handling should use try/catch with proper typing
- Naming: camelCase for variables, PascalCase for types/interfaces
